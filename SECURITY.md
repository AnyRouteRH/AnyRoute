# Security reporting

Please report vulnerabilities using
[GitHub's private vulnerability reporting](https://github.com/AnyRouteRH/AnyRoute/security/advisories/new).
Include affected components, reproduction steps, expected impact and a minimal
test case. Use test keys and local test funds; never include real credentials,
private keys, customer prompts or personal information.

If you cannot use GitHub's private reporting, email Anyroute1@atomicmail.io and we will arrange a
private channel. Do not put exploit details or secrets in the first message.

For support questions that are not security issues, write to Anyroute1@atomicmail.io.

Only the current `main` branch is actively maintained. This project is in
pre-launch development. No production security certification or response-time
guarantee is implied by this policy.

Real-funds launch requires completion of the contract governance, deployment,
credential rotation and recovery gates.
